# 🎬 Movie Explorer App

A Netflix-inspired movie discovery web application built using **HTML, CSS, and JavaScript**, powered by the **TMDB API**.

## 📌 Features

- 🔍 Search for movies in real time
- 🎞 Browse movies by categories:
  - Trending
  - Action
  - Comedy
  - Crime
  - Thriller
- 🎬 Watch movie trailers (YouTube embed)
- ❤️ Add / remove favorites (stored in localStorage)
- 🖼 Movie detail modal with overview, rating, and release date
- 🎨 Netflix-style horizontal scrolling UI
- ⏳ Loading states and error handling

---

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- TMDB API
- LocalStorage
